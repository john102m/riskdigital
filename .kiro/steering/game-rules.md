# Game Rules (Quick Reference)

## Core Mechanics
- 2–6 players (minimum 3 for v1), 42 territories across 6 continents.
- **Objective:** Eliminate all opponents (own all 42 territories).
- **Turn phases:** Reinforce → Attack → Fortify.

## Reinforcement
- Territories owned ÷ 3 (minimum 3) + continent bonuses + card set trade-ins.
- Card escalation (global): 4, 6, 8, 10, 12, 15, then +5 each.
- Forced trade if 5+ cards at start of turn or after elimination capture.
- Territory bonus: +2 on owned territory if traded card matches it.

## Combat
- Attacker rolls 1–3 dice (must have more armies than dice count in source territory).
- Defender rolls 1–2 dice (1 if single army, otherwise chooses).
- Compare highest pairs descending. Defender wins ties.
- After capture: must move troops in (min = dice used, max = source - 1).
- "Blitz" option: repeat until one side falls below threshold.
- Earn one card per turn on first capture.

## Fortify
- Move troops from one owned territory to one adjacent owned territory (v1: adjacent only).
- One move per turn. Can skip.

## Special Events
- **Elimination:** Attacker takes defender's cards. Force trade if >5.
- **Win condition:** One player owns all 42 territories.
